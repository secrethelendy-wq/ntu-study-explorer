# 官方建築定位查證

查證日期：2026-10-11。原始網址完整保留，定位與來源內容分開。

來源：

- [臺大官方校園地圖](https://map.ntu.edu.tw/)
- [官方前端程式](https://map.ntu.edu.tw/index.bundle.js)
- [官方建築 WFS，要求 EPSG:4326](https://map.ntu.edu.tw/geoserver/ntuga/ows?service=WFS&version=1.0.0&request=GetFeature&typeName=ntuga%3Antu_building_bound&outputFormat=application%2Fjson&srsName=EPSG:4326)

在官方程式的網址處理段，先讀取 `cx`、`cy`，再呼叫 `VUe("EPSG:3857","EPSG:4326",[i,o])`，最後用 `camera.setView` 設定視圖。`apKey` 經 `atob` 解碼後用 `ap_key in (...)` 查詢 WFS 建築。因此 cx/cy 是 EPSG:3857 視圖中心，而非準確的建築圖釘。

僅為保留來源中心語意，另存以下轉換結果，網站不直接用它們定位：

```
R = 6378137
longitude = (x / R) * 180 / π
latitude = (2 * atan(exp(y / R)) - π / 2) * 180 / π
```

網站使用 WFS 已提供的 EPSG:4326 建築輪廓，逐筆核對名稱、uid 與 ap_key，計算面積加權的 polygon 重心。取各外環的平面面積重心後依面積加權；先平移至環首點以減少浮點抵消。精度為建築物層級，不聲稱入口或室內座標。
