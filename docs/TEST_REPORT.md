## 驗證方式

功能回歸使用 `tests/e2e/fixtures.ts` 的測試用 SVG 圖磚，避免自動化多尺寸／pan／zoom 反覆請求 OSM 公共服務。這些測試驗證標記、照片、搜尋、篩選、詳細頁、比較、鍵盤、響應式與 file:// 保護，不用它們宣稱真實底圖正常。正式建置不包含測試替代圖磚。

真實底圖驗證使用 Node 靜態 HTTP 伺服器與一般視窗 Chrome，未啟用 routing，未覆寫 User-Agent、Referer 或快取標頭，僅以 CDP 被動讀取 Network 事件。檢查實際 x-blocked、狀態、來源與快取標頭，並等待全部圖片完成繪製。快取驗證使用同一個持續性瀏覽器快取，第二次正常瀏覽相同頁面。

資料證據：`map-network-before.json`、`map-network-after.json`、`map-cache-check.json`、`test-summary.json`。修復細節見 `MAP_FIX.md`。

## 本機預覽與環境限制

本次真實瀏覽器與伺服器在同一個執行階段完成 HTTP 實測。執行沙盒的其他命令／視窗可能無法共享這個 loopback 範圍。使用者應在自己的 Windows 雙擊專案的 `啟動網站.cmd`，保持視窗開啟，再開 http://127.0.0.1:4173/ ；也可執行 `npm run preview`。

請勿以 file:// 測試公共底圖。該模式會保留本機資料功能，但不向 OSM 發送無來源請求。底圖需要網路。手機與平板為 Chrome 裝置模擬，未驗證其他瀏覽器引擎或實體裝置。
